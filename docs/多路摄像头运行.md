# 四路摄像头运行

SRS 主机只采集并发布一次摄像头，输入地址为 /live/multi_camera。板端四个通道拉取同一输入，分别回推 /live/multi_result_1 到 /live/multi_result_4，SRS 界面同屏显示四路结果。

板端配置模板为 config/config_multi_camera.json。先将其中RTMP与MQTT地址改成当前SRS主机IP，确认模型路径与本机文件一致。视频目标30fps，全局推理目标28fps、每路7fps是调度预算，不代表一定能够达到。

编译完成后在项目根目录上传四路配置：

```bash
CONFIG_FILE="$PWD/config/config_multi_camera.json" ./upload_to_board.sh
```

上传脚本仍将选中的配置安装为板端 config_srs_gui.json，因此板端进入部署目录运行 ./start.sh 即可。未设置 CONFIG_FILE 时继续使用原来的单路配置。

SRS输入、四路结果流名必须与板端配置一致。实验计时、固定框和端到端诊断工具不属于正常运行流程。
